# alu-web_react

Front-end curriculum projects for the ALU Web Stack (React) module.

## Projects

| Directory | Topic |
| --- | --- |
| [TypeScript](TypeScript) | TypeScript fundamentals: interfaces, classes, advanced types, ambient namespaces, declaration merging and nominal typing |
| [Webpack](Webpack) | Webpack fundamentals: basic setup, config files, CSS and image loaders, dev server, modules, code splitting and tree shaking |
| [react_intro](react_intro) | React fundamentals: `create-react-app`, JSX, components, Enzyme shallow rendering tests, GitHub Pages deployment and a hand-rolled Webpack + Babel setup |
