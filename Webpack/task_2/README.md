# Task 2 - Adding CSS & images

The task_1 bundle extended with styles and an image.

* `css-loader` and `style-loader` pull `css/main.css` into the bundle.
* `file-loader` and `image-webpack-loader` handle and compress the logo.
* `#logo` is a 200px by 200px element backed by `assets/holberton-logo.jpg`.
* The click counter sits to the right of the button, in bold.

## Usage

```
npm install
npm run build
```

Open `public/index.html` in a browser.
